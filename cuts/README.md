# Cuts

A Cut is the reviewable artefact of this engine: a small JSON file holding the
exact quoted string and the exact citation, approved before any frame is
rendered.

Cuts are **not committed to this public repository**, because each one embeds
the verbatim text of the document it quotes and this repo ships no statutory
text. In an institution's own (private) repository they should be committed —
they are the record of what was published and who approved it.

Corpora (`corpus/`) and renders (`renders/`) are regenerable and gitignored.
